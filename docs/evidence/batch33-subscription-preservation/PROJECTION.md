# Public projection of historical preservation evidence

This directory is an explicitly sanitized project-facing projection of historical review evidence. It is not the byte-identical raw review record, a new independent review, or publication authorization. `projection-origins.json` records original artifact SHA-256 values without private storage locations. `manifest.json` hashes the current projected files; those hashes must not be presented as raw-record identities.

## Exact changes

- Remove machine-specific source/packet roots. Replay source hashes now use repository-relative paths; all 15 complete call arguments, input/output states, return values, guard targets and blocked-I/O results are unchanged
- Reduce the original 635-entry source inventory to the exact nine-source compatibility tuple plus two supporting files used by this bridge. All eleven selected hashes remain exact; unrelated inventory and executor context are omitted
- Normalize the historical command interpreter path to `python` and omit incidental elapsed times. Preserve command arguments, environment, exit codes, output hashes and the two historical pre-integration failures
- Label rewritten review/design records as projections. Retain their historical findings, technical constraints, source tuples and limitations; omit redundant workflow metadata and private-storage references
- Update the verifier and installed manifest pin for this metadata schema. Existing positive/negative controls remain. Added controls execute the unchanged historical runner against the current helper twice and check all 15 guarded calls, complete state/output equality, deterministic results, and semantic tamper rejection independently of artifact hashes

The original 173-file `../subscription-boundaries/` packet is byte-identical, including original/v2 responses, prior failed T38 evidence, historical generation identities, source equality records and historical tests. The exact live source tuple is unchanged. Source/runtime behavior and historical acceptance clauses/layers are not edited.

## Review limits

The historical compatibility review covered the then-existing 45 accepted cases. These bridge records establish no new acceptance, do not independently accept T77/T80, and do not prove native-platform behavior, current account eligibility or entitlement, or permission to perform account/payment/network actions. Historical synthetic/offline results stay historical. The no-I/O instrumentation guards pure helper calls after imports, not an operating-system sandbox.

Sanitization does not turn an original hash into public authentication of absent raw bytes. Selected technical receipts remain available here; larger original review artifacts remain retained outside the public candidate. A future source change invalidates this exact complete tuple rather than enabling an old/new per-file allowlist.
