# 本机路线：固定出口 IP 的三种来源（所有者指定，2026-10-21）

**适用范围：** 只在用户已经选择**本机**运行路线（见 [R-LOCAL](routes-and-platforms.md)）、并要把出口固定为一个 IP 之后使用。选 VM 或 VPS 路线时不触发本文。目标与[现行整机统一路径](agent-remediation.md#ipv4-only-policy)一致：所有流量走同一个指定出口，不泄漏。

本文只讲“怎么得到一个稳定、干净的出口 IP”。Agent 只提供方案和教程指引；不代买、不代配置、不代付款。实际配置前仍走备份、差异展示和逐动作授权，付款由用户本人完成。

## 三种来源

| 来源 | 优点 | 缺点 |
| --- | --- | --- |
| **纯净机场 IP** | 方便，折腾度低 | 纯净、优质的线路价格高；多人共用，风险高 |
| **自建梯** | 价格合适，IP 纯净度高，线路自选；可搭配家宽出口 | 折腾度高 |
| **家宽拼车** | 价格合适，适合小白 | 容易遇到“黑车”；渠道沟通不方便 |

## 社区观点并不一致（请如实告诉用户）

以下来自论坛，是个人经验，不是官方规则，也没有统一结论：

- 多人共用的机场 IP 常被说成不纯，有人称机场 IP 有几百到上千人共用；但也有长期用机场的用户称没出问题，认为封号主要看支付和注册环节，不是 IP（[V2EX t/1218216](https://v2ex.com/t/1218216)）。
- 自建独享 IP（尤其家宽）被一些人认为信誉最好，但也有自建中转（如 Claude Relay、sub2api）后很快被封的案例，当事人怀疑是中转工具或指纹问题（[t/1205805](https://www.v2ex.com/t/1205805)、[t/1199792](https://v2ex.com/t/1199792)）。所以“自建风险极低”只是所有者的判断，不是保证。
- 被多人滥用过的“脏 IP”、短时间频繁切换国家，被认为会增加风险（[t/1151272](https://v2ex.com/t/1151272)）。
- 支付方式、注册邮箱、使用强度被很多人认为比 IP 类型更关键（[t/1148482](https://www.v2ex.com/t/1148482)）；风控是综合判断，单一指标参考价值有限。
- 家宽拼车：论坛里提到“伪家宽”常是几百上千人共用，带宽低，套链式代理后更不稳定（仅作风险提示，不推荐渠道）。

## 自建梯怎么选 VPS

所有者提供了三类 VPS 推荐报告，见 [VPS 推荐报告索引](../sources/vps-recommendations/INDEX.md)：

- **业务**：AWS、Azure、DMIT 等通用机房 VPS。
- **性价比**：VMISS、VMRACK、千宿网络、搬瓦工。
- **高端家宽**：NodeMach、AaITR、QQPW、ResidentialVPS、ZoroCloud 等，对应“自建梯搭配家宽出口”。报告里提到家宽 VPS 国内直连丢包较重时宜配线路机中转。

使用边界：报告里的价格、配置、测试都是历史记录；星级是报告作者的推荐指数，不是验证结论。购买前到商家官网核验当前价格、库存、条款和 IP 状态。千宿网络、NodeMach 两份报告含商家推广或邀请链接，不作排序理由。

## 选好之后

1. 出口入口按[网络与解决方法](network-and-remedies.md)的口径：Claude Code 不直接使用 SOCKS 入口，本地要有 HTTP 或 mixed 入口；配置已导入不等于已生效。
2. 用 [IP 质量与网络测试清单](../sources/S07-vps-script-catalog.md)自行检查出口 IP，由用户在自己的 VPS 上运行，结果只描述当时的观测，不能推出免封概率。
3. 同一台电脑的出口保持稳定：不要频繁切换节点和地区，节点失效时报告不可用，不静默换出口。
4. 支付、注册、使用节奏见[账号注册与使用节奏](account-onboarding.md)和[支付说明](accounts-and-payments.md)。

不承诺免封，也不承诺任何 IP 一定稳定或纯净。
